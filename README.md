# Sistema Integrador do Centro Cearense de Idiomas - SICCI

O **SICCI** é um sistema web desenvolvido para otimizar, facilitar a organização e manipular os dados dos alunos do Centro Cearense de Idiomas (CCI), especificamente para o campus de Crateús.

---

##  Objetivo

Centralizar a gestão acadêmica e administrativa da instituição, oferecendo aos gestores e professores uma ferramenta ágil para o acompanhamento do corpo discente.

---

##  Principais Funcionalidades

*  **Painel Estatístico (Dashboard):** Indicadores analíticos inteligentes com filtros combinados por Turma, Horário, Disciplina, Professor, Módulo e Situação Cadastral.
*  **Gestão de Turmas:** Visualização organizada de alunos divididos por salas e horários específicos de funcionamento.
*  **Estrutura Matricial de Notas:** Lançamento detalhado de avaliações contendo as notas `n1` e `n2` para quatro períodos letivos distintos (`p1`, `p2`, `p3` e `p4`).
*  **Controle de Assiduidade:** Mapeamento interno anual de faltas indexado detalhadamente por meses (0 a 11).
